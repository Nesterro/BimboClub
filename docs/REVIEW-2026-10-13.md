# BimboClub: проверка и модернизация

Основная целевая среда пользователя — **Revit 2024 / .NET Framework 4.8**.
Проверка начата от коммита e15cb161b503821c736b1ea51255ea2222f722a2 (2.4.23).

## Граница проверки

Выполнены сборка решения, проверка источников установки и версии DLL, статический
разбор наиболее рискованных операций, инвентаризация команд и отрисовка WPF-разметки.
Успешная сборка не доказывает правильность геометрии или результатов расчёта.
После подключения Revit 2024 выполнено 30 проверок новой сборки: 12 для копирования
листов и фильтров, 11 для теплопотерь и 7 для пакетных параметров. Использовались
временные документы и отдельная копия тестовой модели; все закрыты без сохранения.
Исходная модель сохранила 5952 элемента. Проверки не покрывают все команды,
полную точность расчётов, Undo, общий доступ и внешний Revit Server.
PR следует оставлять черновиком до завершения сценариев ниже.

Тела скриптов для rvt-mcp сохранены в `tests/Revit2024/*.cs.txt`. Перед повторением
заменить абсолютный путь DLL на свою сборку net48; HeatLossSmoke требует отдельную
копию модели с двумя ограниченными пространствами и семейством HeatLoss_Cube.
BatchParamsSmoke открывает семейство HeatLoss_Cube из активного документа и закрывает
его без загрузки изменений. CoreSmoke создаёт и закрывает два временных проекта.
HeatLossSmoke собирает предупреждения только тестового документа; это не настройка
плагина. После исправления повторяющихся марок предупреждений в тесте не было.

## Известные ограничения и следующий этап

- Поддержка Revit 2021–2023 в старом README не подтверждена: net48 собирается
  с API 2024. Не следует считать эти версии проверенными без отдельных сборок и запусков.
- В проекте остаются обращения к 32-битному ElementId.IntegerValue и сохранение
  ID в int. Нужен последовательный переход на 64-битные ID с миграцией сохранённых схем.
- SAVDecompiled.cs содержит большой действующий модуль редактора правил.
  Его нельзя удалить как «лишнее»: ParamRulesCommand вызывает CmdRuler из этого файла.
  Разделять его на модули следует после тестов формул, фильтров и XML-совместимости.
- Новый маркер принадлежности кубиков не мигрирует старые кубики автоматически:
  при первом повторном расчёте старые элементы остаются. Перед заменой старых данных
  требуется явный сценарий миграции, иначе нельзя надёжно отличить чужие элементы.
- Обновление файлов пока не является атомарной заменой всего каталога. При ошибке
  доступа в середине копирования возможна частичная установка. Нужен staging/rollback.
- Скрипт PublishUpdate.ps1 по-прежнему содержит старую схему публикации с удалением
  одноимённого релиза. Этот скрипт при проверке не запускался; перед выпуском заменить
  публикацией draft-релиза с проверенными артефактами и контрольными суммами.
- Удаление legacy-кода, сторонних DLL bridge и старых тестовых моделей без
  подтверждения их назначения не выполнялось.

## Как повторить проверки

```powershell
dotnet build BimboClub.sln -c Release
dotnet run --project tests/UpdateService.Tests -c Release
dotnet run --project tools/UiPreview -c Release -- . artifacts/ui
.\InstallLocal.ps1 -SkipBuild -Versions 2024 -AddinsRoot "$env:TEMP\BimboClub-InstallTest"
```

UiPreview отрисовывает настоящую XAML-разметку с отключёнными обработчиками.
Он не запускает операции Revit и не заменяет функциональное тестирование в хосте.
Тестовые данные менеджера в превью не являются состоянием установленного Revit.
