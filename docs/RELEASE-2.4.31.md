# BimboClub Tools 2.4.31 — 16 ноября 2026

Устранён вызов `FilterableValueProvider.GetStringValue`, на котором в версии
2.4.30 возникала ошибка `An internal error has occurred` при создании 3D-схем.

- Значение читается напрямую из выбранного параметра: встроенного по ID,
  проектного/общего по его определению, без поиска по отображаемому имени.
- До чтения проверяются наличие параметра, строковый тип и наличие значения.
- Если значение экземпляра отсутствует, проверяется параметр типоразмера.
- Перед сбором значений выполняется регенерация документа.
- Настоящая ошибка чтения больше не теряет контекст: сообщение указывает
  идентификаторы параметра и элемента; ошибка не превращается в скрытую установку.

Сохранены поддержка ПВ-установок с несколькими системами, скрытие осей, уровней,
связей и лишних категорий. После установки повторите создание нужных схем
с прежними именами и префиксами.

Проверено без запуска Revit и моделей: 15 проверок чтения на имитаторе API
и 29 проверок принадлежности системам на каждой платформе; компиляция генератора
с настоящим API Revit 2023 и сборки обоих пакетов. Внутренняя ошибка Revit
в пользовательской модели не воспроизводилась; исправление основано на её стеке.
