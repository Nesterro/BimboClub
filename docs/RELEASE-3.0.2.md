## BimboClub Tools и Manager 3.0.2

- «Схемы и виды» → «Копировать фильтры» переносит параметрические фильтры и фильтры выбора между видами и шаблонами. Сохраняются графика, видимость и состояние «Включён».
- У 46 команд и 7 меню ленты свои пиктограммы. Перед названием вкладки BimboClub отображается розовый кружок.
- Менеджер обновлений и окно «О плагине» используют фирменную графитово-розовую палитру. Менеджер ставит новые сборки в отдельные каталоги.

Обновление Tools появится в менеджере после проверки обновлений. При первом переходе с 2.x перезапустите Revit после установки. Для нового интерфейса и обновлений в открытом Revit используйте BimboClub Manager 3.0.2.

Ручная установка доступна из `bimboclub_net48.zip` для Revit 2021–2024 и `bimboclub_net8.zip` для Revit 2025–2026. `BimboClubManager.exe` — самостоятельный менеджер для Windows x64.
