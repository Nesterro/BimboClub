# BimboClub Tools 2.4.32 — 17 ноября 2026

В расстановку и объединение отверстий добавлены два независимых шага округления:

- **Размеры вверх, шаг (мм)** — ширина, высота и глубина округляются вверх.
- **Низ от уровня вниз, шаг (мм)** — фактическая нижняя грань округляется вниз
  относительно уровня отверстия; высота увеличивается для сохранения верхней границы.

По умолчанию оба шага равны **10 мм**. Значение **0** отключает соответствующее
округление. Принимаются десятичные значения с точкой или запятой.

Настройки действуют при расстановке в стенах/перекрытиях, ручном и пакетном
объединении, а также в команде «Задание на отверстия». Округление выполняется
после вычисления размеров и зазоров. При объединении сохраняется уровень первого
исходного отверстия; если он не задан, выбирается ближайший уровень ниже точки
размещения, а ниже всех уровней — самый нижний.

Низ измеряется по объёмной геометрии, без предположения о расположении точки
вставки семейства. Размеры и итоговые вертикальные границы проверяются перед
удалением исходных отверстий. Неподходящий параметр, отсутствие объёмной геометрии
или запрет перемещения приводят к отмене операции. Параметры размеров должны быть
редактируемыми параметрами длины экземпляра; выбранная высота должна управлять
вертикальным размером семейства. Для семейств без измеримой объёмной геометрии
можно отключить округление низа, оставив округление размеров.

Проверено без запуска Revit и моделей: 75 проверок на каждой платформе с настоящим
кодом и тестовым API; компиляция с API Revit 2023; сборки для .NET Framework 4.8 и
.NET 8. Панель настроек отрисована для проверки читаемости. Реальные семейства,
размещение и транзакционный откат в Revit в этой задаче не проверялись.
