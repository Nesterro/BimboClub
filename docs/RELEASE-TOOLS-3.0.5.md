## BimboClub Tools 3.0.5

- Пакетное объединение отверстий предлагает типы с двумя и более экземплярами в выбранной области. Зазор измеряется между краями отверстий в стене или перекрытии.
- При объединении можно округлять размеры вверх и отметку низа вниз с сохранением просвета.
- Повышен контраст списков, полей и кнопок в окнах инструментов.

В Revit 2024 проверены выбор нужного типа и объединение на копии модели. Отверстия в соседних стенах остались раздельными.

Обновление доступно через BimboClub Manager 3.0.3. Для ручной установки используйте `bimboclub_net48.zip` с Revit 2021–2024 или `bimboclub_net8.zip` с Revit 2025–2026.
