## BimboClub Manager 3.0.3

На панели задач и в списке приложений Windows теперь значок с чёткими буквами **BC**. В заголовке менеджера — фирменный розовый кружок.

`BimboClubManager.exe` — самостоятельное приложение для Windows x64. Менеджер получает BimboClub Tools 3.0.2 из основного канала обновлений.
