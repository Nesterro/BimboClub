# BimboClub Tools 2.4.29 — 16 ноября 2026

В команде создания 3D-схем добавлена отдельная настройка видимости для вентиляции.

- На вентиляционном виде отключаются Revit-связи, координационные модели и категории связанных CAD-файлов.
- Отключаются обобщённые модели, трубы, гибкие трубы, трубы-заполнители, соединительные детали, арматура, изоляция, изготовленные трубопроводы, сантехнические категории и спринклеры.
- Категория «Оборудование» остаётся включённой и подчиняется фильтру выбранной системы.
- Правило применяется при создании и повторной обработке вентиляционного вида; трубопроводные схемы сохраняют прежнее поведение.

Проверено компиляцией с API Revit 2023 и сборкой плагина для .NET Framework 4.8
и .NET 8. Модели и работающий Revit не использовались; проверка видимости в реальной
модели не выполнялась. Предыдущие исправления пакетных параметров и ADSK сохранены.

Обновление доступно через существующий менеджер BimboClub. Перед установкой закройте Revit.
