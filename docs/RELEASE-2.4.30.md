# BimboClub Tools 2.4.30 — 16 ноября 2026

3D-схемы: отключены оси и уровни; исправлена видимость установок, обслуживающих
несколько систем.

- ПВ-установка со значением «В7.3,П7.3,В7.3» остаётся на схемах В7.3 и П7.3.
- Имена сопоставляются целиком: В7.3 не совпадает с В7.30, В7 или АВ7.3.
- Учитываются пробелы, повторения имён и разделители списка.
- Оси и уровни скрываются как при создании, так и при повторной обработке схемы.
- Настройки вентиляционной видимости из 2.4.29 и прежние исправления сохранены.

После обновления повторно запустите создание нужных схем с прежними именами и
префиксами: существующие виды получат исправленный фильтр и настройки видимости.
Если состав систем установки изменится позже, повторите создание схемы: фильтр
учитывает полные комбинации имён, существующие на момент запуска.

платформе (.NET Framework 4.8 / .NET 8), компиляция полного генератора с API Revit
2023, сборки обоих пакетов. Визуальная проверка в пользовательской модели не
проводилась.
