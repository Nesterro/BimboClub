# BimboClub Tools 2.4.28 — 16 ноября 2026

Исправлена запись заполненных значений в инструменте «Пакетные параметры»
в редакторе семейства (.rfa).

- Значения записываются во все типоразмеры с учётом типа параметра и единиц документа.
- При отсутствии типоразмеров создаётся «Тип 1».
- Редактирование значения заменяет сохранённую формулу; формулы вводятся с `=`.
- После замены параметра используется возвращённый Revit объект.
- Все параметры создаются до назначения формул; ошибки записи больше не скрываются.
- Пакет проверяется перед фиксацией; при ошибке изменения откатываются.

Перенесено на актуальный main после 2.4.27. Исправления полей ADSK и миграции
встроенных параметров из предыдущих выпусков сохранены.

Проверено без запуска Revit и моделей: 39 проверок записи значений и 315 прежних
ADSK-проверок на каждой платформе (.NET Framework 4.8 / .NET 8), компиляция модуля
с установленным API Revit 2023, полные сборки плагинов для обеих платформ.
Сборки проходят с существующими предупреждениями. Работа в реальном .rfa
не проверялась.

Для менеджера используются версионные ZIP на GitHub raw, закреплённые на commit SHA.
Пакеты также доступны как вложения GitHub Release. Переустановка менеджера не нужна.
