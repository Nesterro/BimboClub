# BimboClub Tools — Пакет плагинов для Autodesk Revit (2021–2026)

**BimboClub Tools** — комплект утилит для автоматизации проектирования инженерии (MEP), строительных конструкций и архитектурного моделирования в Autodesk Revit под Windows. Проект собирается для .NET Framework 4.8 с API Revit 2024 и .NET 8.0-windows. Основная целевая версия — Revit 2024. Совместимость с Revit 2021–2023 и запуск в Revit 2025–2026 требуют отдельных проверок в хосте.

Состояние модернизации, выполненные проверки и сценарии приёмки: [отчёт по проверке](docs/REVIEW-2026-10-13.md).

## 🚀 Основные Модули и Инструменты

### 🛠️ 1. Редактор правил (BimboClub RuleEditor) — *Новое*
Полноценный автономный модуль для пакетного вычисления параметров и автозаполнения спецификаций по заданным формулам и правилам.
- **Интерфейс**: Редактор правил использует существующий модуль WinForms; остальные обновлённые окна WPF используют нейтральные графитовые поверхности и синий акцент.
- **Служба правил**: Иерархическое дерево правил (`RuleSet` -> `RuleGroup` -> `RuleItem`).
- **Конструктор условий**: Поддержка считывания данных с экземпляра (`Self`), типа (`Type`), хоста (`Host`) и родительского элемента (`Parent`). Операторы: `=`, `≠`, `содержит`, `не содержит`, `начинается с`, `заканчивается на`, `>`, `<`, `пусто`, `не пусто`.
- **Конструктор действий**: Составное именование (префиксы/суффиксы), замена подстрок, округление числовых значений, вычисление математических формул видов `[Диаметр] * 3.14 + 100`.
- **Сохранение/Загрузка**: Поддержка стандартизированных XML-файлов правил `.xml` с обратной совместимостью.

### 📐 2. MEP Инженерия и Сети
- **3D схемы**: Создание изолированных 3D-видов для инженерных систем.
- **АвтоМарки**: Автоматическая расстановка выносок и марок элементов на виде с учётом масштаба.
- **Умная трассировка (Router)**: Прокладка обходов («уток») для воздуховодов и труб при пересечении с конструкциями.
- **Нумерация стояков**: Определение и автоматическая нумерация вертикальных труб (стояков), пересекающих перекрытия.
- **Подключение труб**: Автоматическое подключение двух перпендикулярных труб (отводы 90°/45°).
- **Расстановка по сети**: Расстановка подвесов, креплений и датчиков вдоль осей инженерных сетей с заданным шагом.

### 🏢 3. Отверстия в Конструкциях
- **Отверстия в стенах и полах**: Автоматическая расстановка отверстий в местах пересечений с инженерными коммуникациями.
- **Объединение отверстий**: Умное объединение группы ближних отверстий в одно с вычислением габаритов.

### 📋 4. Импорт, Экспорт и Отчёты
- **Экспорт чертежей (PrintMaster)**: Пакетный экспорт листов в PDF, DWG и IFC с автоматическим распознаванием рамок и форматов.
- **Импорт/Экспорт Excel**: Экспорт видов элементов в таблицы Excel и обратный импорт ведомостей на чертежные виды Revit.
- **Экспорт JSON (LES CAD/BIM)**: Экспорт геометрии и параметров модели в формат LES JSON.

## 💻 Установка и Сборка

### Быстрая установка в Revit:
Запустите скрипт установки в PowerShell:
```powershell
.\InstallLocal.ps1 -Versions 2024
```
Закройте Revit перед установкой. Скрипт автоматически скомпилирует плагин и развернёт библиотеки, манифест и иконки в `%APPDATA%\Autodesk\Revit\Addins\2024`. Параметр `-Versions` задаёт нужные годы; без него скрипт выбирает 2021–2026, что само по себе не подтверждает совместимость.

### Сборка через dotnet CLI:
- **Сборка всех версий (.NET 4.8 + .NET 8.0-windows)**:
  ```bash
  dotnet build BimboClub.sln -c Release
  ```
