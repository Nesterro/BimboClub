# DuctWallOpenings — плагин Revit 2024

Плагин для **Autodesk Revit 2024** автоматически расставляет отверстия в местах пересечения воздуховодов со стенами и перекрытиями. Поддерживает связанные модели, выбор семейства и параметров, фильтрацию по выделению и текущему виду.

---

## Возможности

- ✅ Расстановка отверстий **в стенах** в местах пересечения с горизонтальными воздуховодами.
- ✅ Расстановка отверстий **в полах/перекрытиях** для вертикальных воздуховодов.
- ✅ Поддержка **связанных моделей** (Revit Links) — стены и полы из связей тоже учитываются.
- ✅ **Выбор семейства** отверстия из всех загруженных в проект (с поиском).
- ✅ **Гибкая привязка параметров** — выбор имён параметров ширины, высоты и глубины из существующих в семействе.
- ✅ **Запас по габаритам** (отдельно для ширины/высоты и для глубины) — отверстия можно «выпустить» наружу из стены/пола.
- ✅ Фильтр **«только выбранные воздуховоды»** (если что-то выделено перед запуском).
- ✅ Фильтр **«только воздуховоды на текущем виде»**.
- ✅ Автоматический поворот отверстия по направлению воздуховода (для стен).
- ✅ Иконки кнопок на ленте (генерируются автоматически).

## Требования

- **Autodesk Revit 2024** (установлен по стандартному пути `C:\Program Files\Autodesk\Revit 2024\`).
- **Visual Studio Build Tools 2022** (или Visual Studio 2019/2022) с компонентом «Средства сборки .NET Desktop».
- **Microsoft .NET Framework 4.8 Developer Pack**: <https://dotnet.microsoft.com/download/dotnet-framework/net48> → раздел *Developer Pack*.
- **PowerShell** (для генерации иконок) — по умолчанию есть в Windows.

## Установка

1. Положите файлы в любую папку, например `C:\BIM\Plugins\DuctWallOpenings\`.
2. Закройте Revit, если он открыт.
3. Запустите **`Install.bat`** двойным кликом.
4. Дождитесь сообщения «Установка завершена».
5. Запустите Revit 2024 — на новой вкладке **«MEP Инструменты»** появится панель **«Отверстия»** с двумя кнопками:
   - 🧱 *Отверстия в стенах*
   - ⬛ *Отверстия в полах*

### Куда устанавливается

| Что | Путь |
|---|---|
| DLL и иконки | `%APPDATA%\Autodesk\Revit\Addins\2024\DuctWallOpenings\` |
| Манифест .addin | `%APPDATA%\Autodesk\Revit\Addins\2024\DuctWallOpenings.addin` |

### Удаление

Удалите папку `DuctWallOpenings` и файл `DuctWallOpenings.addin` из `%APPDATA%\Autodesk\Revit\Addins\2024\`.

## Подготовка модели

### 1. Семейство отверстия

В проект должно быть загружено **семейство обобщённой модели** (Generic Models), используемое в качестве отверстия. Желательные параметры (имена могут быть любыми — выбираются в окне плагина):

- **Ширина** — длина отверстия по горизонтали;
- **Высота** — высота отверстия по вертикали;
- **Глубина / Толщина** — толщина (привязывается к толщине стены/пола).

Если в имени семейства есть слово «отверстие» или «opening», плагин автоматически выберет его в списке.

### 2. Воздуховоды

Поддерживаются **прямолинейные** воздуховоды (прямоугольные и круглые). Гибкие/изогнутые игнорируются.

### 3. Стены и полы

- Стены — только **прямолинейные**. Витражи, скруглённые и стены по поверхности пропускаются.
- Полы — любые. Точка вставки определяется как пересечение оси воздуховода с серединной плоскостью пола.

## Использование

### Расстановка отверстий в стенах

1. Откройте проект с воздуховодами и стенами (своими или из связей).
2. *(Опционально)* Выделите нужные воздуховоды на виде.
3. На ленте → вкладка **«MEP Инструменты»** → панель **«Отверстия»** → кнопка **«Отверстия в стенах»**.
4. В открывшемся окне:
   - Введите часть имени семейства в поле **«Поиск»** (опционально).
   - Выберите **семейство (тип)** в списке.
   - Подберите **параметры ширины/высоты/глубины** (или оставьте «не задавать»).
   - Задайте **запас по ширине/высоте** в мм (по умолчанию 50).
   - Задайте **запас по глубине** в мм — насколько отверстие должно «торчать» из стены (по умолчанию 50).
   - При желании отметьте:
     - ☑ **Использовать только выбранные воздуховоды** (доступно, если что-то выделено).
     - ☑ **Только воздуховоды на текущем виде**.
5. Нажмите **OK**.

### Расстановка отверстий в полах

Аналогично, но для **вертикальных** воздуховодов (наклон > 45° от горизонтали). Кнопка **«Отверстия в полах»**.

### Логика разделения

| Кнопка | Какие воздуховоды учитывает |
|---|---|
| **Отверстия в стенах** | Горизонтальные и наклонные ≤ 45° |
| **Отверстия в полах** | Вертикальные и наклонные > 45° |

---

## Параметры окна

| Поле | Описание |
|---|---|
| **Поиск** | Фильтр списка семейств по подстроке. |
| **Семейство (тип)** | Список всех загруженных семейств в формате `ИмяСемейства : ТипРазмер`. |
| **Параметр ширины** | Имя параметра в семействе для записи ширины отверстия. Можно «не задавать». |
| **Параметр высоты** | Имя параметра в семействе для записи высоты. |
| **Параметр глубины** | Имя параметра для толщины отверстия. |
| **Запас по ширине/высоте, мм** | Прибавляется к габаритам воздуховода. |
| **Запас по глубине, мм** | Прибавляется к толщине стены/пола, чтобы отверстие выпирало. |
| ☑ Только выбранные | Использовать только воздуховоды, выделенные перед запуском. |
| ☑ Только текущий вид | Использовать только воздуховоды, видимые на активном виде. |

---

## Примеры формул

При воздуховоде **400 × 250 мм** в стене **200 мм**, при запасах ширина/высота = 50 мм, глубина = 50 мм:

- **Ширина отверстия** = 400 + 50 = **450 мм**
- **Высота отверстия** = 250 + 50 = **300 мм**
- **Глубина отверстия** = 200 + 50 = **250 мм** (отверстие торчит по 25 мм с каждой стороны, если семейство симметричное)

## Ограничения

- Только **прямолинейные** воздуховоды и стены.
- В **связанных моделях** отверстия не вырезаются (Revit API не позволяет редактировать связи) — отверстия создаются только в текущем документе.
- Если у воздуховода нет параметра диаметра/ширины (нестандартный тип) — будут использованы нулевые габариты + запас.
- Витражные стены, стены по поверхности и нелинейные элементы пропускаются.

## Решение проблем

### При запуске `Install.bat` ошибка «Не удалось найти SDK Microsoft.NET.Sdk»

Установите **Visual Studio Build Tools 2022** с компонентом *«.NET desktop build tools»* через Visual Studio Installer.

### Ошибка «не найдены ссылочные сборки для .NETFramework v4.8»

Установите **Microsoft .NET Framework 4.8 Developer Pack**:
<https://dotnet.microsoft.com/download/dotnet-framework/net48>

### Ошибка при копировании DLL

Закройте Revit перед запуском `Install.bat` — DLL занята процессом.

### В Revit «не найдена сборка надстройки»

Проверьте, что в файле `DuctWallOpenings.addin` указан **абсолютный путь** к DLL, и что DLL действительно лежит в `%APPDATA%\Autodesk\Revit\Addins\2024\DuctWallOpenings\`.

### Не появились иконки на кнопках

Иконки генерируются через PowerShell. Если политика выполнения PowerShell на вашей машине запрещает скрипты — иконки не создадутся, но плагин будет работать без них.

Можно положить **свои** PNG 32×32 в папку `%APPDATA%\Autodesk\Revit\Addins\2024\DuctWallOpenings\` с именами `wall_icon.png` и `floor_icon.png`.

### Отверстия ставятся, но в неправильном направлении

Откройте семейство отверстия в редакторе и убедитесь, что:
- «лицо» (плоскость, на которую смотрит `FacingOrientation`) направлено **вдоль воздуховода** (т.е. отверстие будет «смотреть» в направлении движения воздуха);
- опорные плоскости геометрически правильно ориентированы.

### Сообщение «Создано отверстий: 0»

Возможные причины:
- Воздуховоды и стены не пересекаются геометрически (например, разные уровни).
- Стены — нелинейные (витражи, скруглённые).
- Включены оба фильтра, и под них ничего не подходит.
- Воздуховоды не того типа (например, для команды «в полах» нужны вертикальные).
